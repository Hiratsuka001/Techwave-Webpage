# TechWave Podcast Website

TechWave is a modern, responsive landing page for a technology podcast. It features a sleek dark theme with vibrant gradients, highlighting the latest tech insights, productivity hacks, and personal growth stories.

---

## 🚀 Live Demo
https://hiratsuka001.github.io/Techwave-Webpage/

## 📋 Project Overview
The **TechWave** landing page is designed to showcase podcast episodes and connect with a global community of tech enthusiasts. It includes a dynamic hero section, detailed "About" and "Features" areas, a featured episodes grid, and a host introduction.

## ✨ Key Features
* **Responsive Navigation**: A clean navbar with smooth scrolling to sections like About, Episodes, and Host.
* **Interactive Stats**: Displays key metrics such as monthly listeners, episodes published, and average rating.
* **Feature Showcase**: Highlights core benefits like premium audio quality, mobile-friendliness, and exclusive interviews using a modern grid layout.
* **Episode Gallery**: A grid of featured episodes with custom play buttons and duration indicators.
* **Meet the Host**: A dedicated section introducing the host with integrated social media links.
* **Fully Responsive**: Optimized for desktop, tablet, and mobile devices using CSS media queries.

## 🛠️ Technology Stack
* **HTML5**: Structured with semantic elements for better accessibility.
* **CSS3**: Custom styling with a focus on dark mode aesthetics, gradients, and flex/grid layouts.

## 📦 Dependencies
This project utilizes external CDNs for styling and icons:
* **Font Awesome (v6.5.2)**: For social icons and UI elements.
* **Google Fonts API**: For "Inter" typography.

## 💻 Local Setup Guide
To run this project on your local machine:

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/Hiratsuka001/Techwave-Webpage.git
    ```
2.  **Navigate to the Directory**:
    ```bash
    cd Techwave-Webpage
    ```
3.  **Ensure Assets are Present**:
    Make sure you have an `assets/` folder containing necessary images like `hero-bg.png`, `microphone.png`, and episode thumbnails.
4.  **Open the Project**:
    Simply open the `index.html` file in any modern web browser to view the site.
